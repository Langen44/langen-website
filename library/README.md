# Photo library

Web-ready originals (2400 px wide, WebP) from the 2025–26 shoots: Gun Hill Studios macros, studio Lightspeed, the
February 2026 pub location set, factory and Two Stroke sets, Goodwood, and the Gun Hill Studios film.
Nothing in here is published. To use one on the site, convert it to JPG into `assets/` with a descriptive name
(`python3 tools/import-image.py "library/lightspeed/<file>.webp" assets/ls_something.jpg`) and reference it from content or page code.
